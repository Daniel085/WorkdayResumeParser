🔧 Fix Chrome AI

You got this error: Cannot read properties of undefined (reading 'languageModel')

❌ window.ai is undefined

This means: Chrome AI is not enabled yet.
Checking current AI status...

Follow These Steps:

1 Enable Flag #1: Prompt API

Click this link to open the flag page in a new tab:

🔧 Open Prompt API Flag
On that page:
  1. Find the dropdown (currently says "Default")
  2. Change it to: Enabled
  3. Don't close the tab yet!

2 Enable Flag #2: On-Device Model

Click this link to open the second flag:

🔧 Open On-Device Model Flag
On that page:
  1. Find the dropdown (currently says "Default")
  2. Change it to: Enabled BypassPerfRequirement
  3. Look for a blue "Relaunch" button at the bottom of the page

3 Relaunch Chrome

⚠️ CRITICAL STEP: You MUST click the blue "Relaunch" button that appears at the bottom of the chrome://flags page. Just closing and reopening Chrome won't work!

After you change BOTH flags, Chrome will show a blue button at the bottom that says Relaunch.

Click that button. Chrome will close and reopen with AI enabled.

4 Wait for Model Download (First Time Only)

After Chrome relaunches, it needs to download Gemini Nano (~1.5GB). This happens automatically in the background.

Expected wait time:
  • Fast connection: 2-5 minutes
  • Slow connection: 5-15 minutes

You can continue using Chrome while it downloads.

5 Verify It's Working

After Chrome relaunches and waits a few minutes, test if AI is ready:

Or manually check:

  1. Open DevTools: Cmd + Option + J (Mac) or F12 (Windows/Linux)
  2. Go to the Console tab
  3. Paste this code:
(await window.ai?.languageModel.capabilities())?.available
What you should see:
  • "readily" = ✅ AI is ready!
  • "after-download" = ⏳ Model is downloading (wait a bit longer)
  • undefined = ❌ Flags not enabled or Chrome not relaunched
🎉 Success! Chrome AI is now enabled. You can now use the resume parser with AI!

Still not working?

If you've done all steps and still get errors:

  1. Make sure you're using Chrome Stable v127+ (you have v142, so ✅)
  2. Try closing ALL Chrome windows and reopening
  3. Check if you have enough disk space (~22GB free needed)
  4. Try the test page without AI first: test-pdf-only.html
