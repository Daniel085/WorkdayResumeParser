🚀 Enable Chrome AI (Gemini Nano)

Checking Chrome AI status...

Step 1: Enable Prompt API Flag

This enables Chrome's built-in AI language model (Gemini Nano).

🔧 Open Prompt API Flag

Set to: Enabled

Step 2: Enable On-Device Model Flag

This allows Chrome to download and use the AI model locally.

🔧 Open On-Device Model Flag

Set to: Enabled BypassPerfRequirement

⚠️ Important: After changing BOTH flags, Chrome will show a "Relaunch" button at the bottom of the flags page. Click it to restart Chrome.

Step 3: Verify AI is Working

After restarting Chrome, open DevTools Console (F12 or Cmd+Option+J) and paste this:

(await window.ai?.languageModel.capabilities())?.available

Expected result:

  • "readily" = ✅ AI is ready to use!
  • "after-download" = ⏳ Model is downloading (wait a few minutes)
  • undefined = ❌ Flags not enabled correctly

Step 4: Test the Parser

Once AI is ready, go back to the test page:

🧪 Open Resume Parser Test
💡 Pro Tip: The first time you use Chrome AI, it may download the Gemini Nano model (~1.5GB). This happens in the background and can take 5-10 minutes depending on your connection.
